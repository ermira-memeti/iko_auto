# Source traceability verification
The paper reports 49 distinct source quotations across 27 insurer-document/page pairs.
An independent automated quotation-location check in the revision workflow matched
all 54 assertion source references to the PDF pages and all 49 distinct quotations
after whitespace normalization. Exact page and text evidence is not redistributed
in this public supplementary package. This check is location-only: it does not
establish semantic completeness or agreement on contractual interpretations.
Full rerunning requires the locally acquired source policy PDFs and the original
documented assertion-level provenance dataset.
