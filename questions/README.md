# Evaluation question sets

- `development_questions_50.csv`: 50 development-informed questions (10 per insurer). Failures on this set informed graph extensions and routing decisions.
- `h1_questions_50.csv`: 50 subsequent questions (10 per insurer) on the same five policy booklets. H1 is a new-question evaluation on known documents, not an unseen-policy benchmark.

Public fields are limited to question ID, insurer, category, question text and split.
