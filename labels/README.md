# Public relevance labels

These files are text-minimized public derivatives. Full policy passage text and evidence-quote fields are intentionally omitted. Passage identity is retained through `chunk_id`, `source_path` and page number.

- `development_reviewed_519_public.csv`: 519 Development question-passage pairs. The two retained reviewer files agree on the final relevance value for all 519 pairs.
- `h1_adjudicated_533_public.csv`: 533 H1 question-passage pairs, including final and pre-adjudication reviewer grades.

The public files are intended to reproduce the numerical evaluation without redistributing large extracts of third-party policy documents.
