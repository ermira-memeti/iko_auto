# IKO-Auto competency questions (design requirements, not validated results)

1. Which coverage provisions belong to a particular policy version?
2. Which exclusions restrict a named coverage?
3. Does an exclusion have an explicitly documented exception?
4. What deductible and limit apply to a coverage?
5. Which source passage supports a given coverage/exclusion relationship?
6. Which claim event and cause are linked to a claim?
7. Which damage categories and severities are associated with a claim?
8. Which risk factors are recorded for a policyholder?

**Caution:** The ontology is a schema. Answering these questions about actual policies requires policy-specific RDF instances with source provenance. No such instance dataset is included.
